# BUILD 255.1 — MULTISOURCE RESEARCH

## Purpose
Eliminate single-path research acquisition failures while keeping newsroom quality fail-closed.

## TechVerse acquisition flow
1. Stable core research hint.
2. Official technology newsroom hubs.
3. Direct HTML link extraction with Browser Run links fallback.
4. Qwen assignment editor selects the newest consequential supported topic.
5. Targeted news-feed discovery attempts cross-source corroboration.
6. Source pages are read with Browser Run Markdown using `networkidle2`.
7. If Browser Markdown is empty or blocked, direct HTTP fetch + safe text extraction is used as fallback.
8. KAI Research Director synthesizes only from rendered/read evidence.
9. Independent Research Standards Board must score the packet >= 8.5.

## Hard quality contract
- TechVerse Latest First.
- Prefer primary/official evidence.
- At least 4 supported verified facts.
- At least 2 exact usable source URLs.
- No memory-based factual additions.
- Research below 8.5 is blocked before MATERIAL.

## Safety scope
No changes to Meta connector, Facebook Page routing, Page IDs, secrets/tokens, caption cleaner, poster renderer, or publish payload/path.
