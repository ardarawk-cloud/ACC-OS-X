# ACC OS X Genesis Alpha v1.0.0

ACC OS X has reached its first stable Genesis Alpha milestone.

This release consolidates Builds 008–020 into a unified local-first enterprise operating environment.

Important:
- External AI providers are not connected in this release.
- Worker execution is deterministic local orchestration.
- Cloud sync is not included.
- Device CPU/RAM values shown in the interface are local UI telemetry indicators.
