# BUILD 253 — KAI CREATIVE ENGINE v1

Status: PRODUCTION CANDIDATE

## Objective
Raise ACC OS X from generator-first automation to deliberate studio production intelligence.

## Creative flow
1. Base production worker creates a grounded draft.
2. KAI Editorial Director rewrites SCRIPT for clarity, originality, hook, usefulness and channel fit.
3. KAI Senior Editorial Critic scores the material. Below 8.0 triggers one rewrite; still below threshold blocks the mission.
4. KAI Senior Art Director creates a structured, topic-grounded visual concept for POSTER.
5. KAI Visual Creative Director independently scores creativity and art direction. Creative < 8.2 or Art Direction < 8.2 triggers one rewrite; still below threshold blocks the mission.
6. AI supplies hero artwork only.
7. Studio Poster Renderer assembles deterministic branding, hierarchy and information architecture.
8. Intelligent Studio QC requires real sources, evidence coverage, Studio Renderer proof and KAI creative scores before publish.

## Poster art-direction contract
Required fields:
- PUBLIC TOPIC
- PRIMARY VISUAL BASIS
- CREATIVE CONCEPT
- HERO SUBJECT
- COMPOSITION
- CAMERA LANGUAGE
- LIGHTING
- COLOR DIRECTION
- ATMOSPHERE
- NEGATIVE SPACE
- EDITORIAL ENERGY
- QUALITY TARGET: STUDIO CONTENT PREMIUM

## Quality thresholds
- Editorial score >= 8.0
- Creative score >= 8.2
- Art-direction score >= 8.2
- At least one real research source
- Adequate evidence coverage
- 1080x1920 Studio Renderer proof
- Dense Studio Content layout and channel visual kit

## Fail-closed rule
If the creative model cannot create or revise an output above threshold, production HALTS. A mediocre fallback is not published.

## Safety scope
No change to Meta connector, Facebook Page routing, Page IDs, secrets/tokens, publishing payload, caption cleaner, or production `worker.js`.
