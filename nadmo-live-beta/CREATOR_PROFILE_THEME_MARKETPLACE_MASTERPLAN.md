# NADMO LIVE — KIN-inspired creator-customizable ME (locked direction)

Owner directive, 10 October 2026.

## Product boundary
- **ME is a creator's individual page**, not a dashboard mirror. No balance, cashout amount, or earnings displayed publicly. Wallet and payout remain accessible privately under ME's three-dot settings.
- LIVE / SOSIAL / signature skewed-lime GO LIVE / PESAN / ME remain globally stable, simple and accessible. Custom theme/font/cover NEVER changes system navigation, critical controls, safety UI, or financial screens.
- SOSIAL shows only the author's chosen display name. Pressing it opens that creator's public ME, with the user's own chosen theme, bio, avatar and permitted links. Username remains a stable unique routing identifier (e.g. public profile URL), and may be shown discreetly inside profile details.
- Follow, like, comment, direct-share to already-consented PESAN threads, external share, and repost are account-bound actions. Only a user's explicitly reposted content is visible under reposts in their ME; ordinary posts are published and managed in SOSIAL.
- Creator links may include YouTube, TikTok, Instagram, WhatsApp, external websites, businesses, bookings, other lawful destinations. HTTPS-only plus security review, illegal-gambling block/appeals. Never promise foolproof classification solely from keywords.

## Profile visual system
Phase 1: server-persisted, allowlisted first-party skin preset + font + cover pattern, with accessible contrast. Safe CSS scoped solely to profile elements. Android and PC consistency.
Phase 2: creator-authored themes and hero/thumbnail images in moderated static asset storage. Require asset validation, copyright rights, accessibility, responsive behavior, content scanning and strict CSS/data limits. Absolutely no third-party JavaScript, HTML execution, remote scripts, hidden tracking, iframe injection or overriding app navigation. Theme preview/sandbox and revocation controls.
Phase 3: **theme marketplace** for creators to list free or paid themes, opt-in installs, public author attribution, ratings/complaints and transparent rev-share. Only enable paid checkout, settlement, refunds and creator withdrawals after compliant acquiring/bank, tax, accounting, copyright/IP, and fraud controls are operational. No sale buttons accepting real funds while payment platform is not operational. Creator can remove their own theme; preserve purchasers' licensed usage as rules require. Avoid exploitative pricing, hidden fees or forced minimum withdrawals.

## Media expansion
- Video from external provider links is usable while independent storage is not ready.
- Direct video file uploads must use configured private-beta R2 (or equivalent) and real runtime verification, with size, type, duration, abuse reporting, moderation, deletion and quotas. Never claim file-upload READY from a disabled R2 binding.
- Comments/likes/reposts are real persistent server interactions; avoid faking engagement.
- Privacy-by-default, no wallet contents on public surfaces.

## QA acceptance
- Profile skin selection persists on reload and between Android WebView and PC via same account.
- Theme customization never changes navigation, LIVE, safety or wallet.
- Clickable display names navigate to correct public profile and no duplicate @handle in SOSIAL card header.
- No arbitrary income disclosure; wallet remains accessible only from private preferences.
- Link safety enforced server side, not only in UI.
- Repost reflects real original attribution and can be removed; deleted original doesn't remain usable.
- Every commercial marketplace release subject to separate legal, security, financial and owner QC.
