# ACC OS X Build 011 — Stable AI Core

## Implemented
- Global Command Bar available from every section
- Stable event binding with duplicate listener protection
- Empty-command validation
- Persistent AI Job Manager
- Command history and status display
- Debug & Recovery panel
- Window error and promise rejection capture
- Self-test diagnostics
- AI Core recovery
- Enter shortcut on global command input
- Ctrl+Enter shortcut inside AI Core command console
- Build 010 data remains compatible

## Usage
1. Type a command in the global command bar.
2. Press RUN or Enter.
3. Open AI Core.
4. Press PROCESS NEXT JOB.
5. Inspect the job in AI Job Manager.

This build remains in LOCAL ORCHESTRATION mode.
