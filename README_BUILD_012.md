# ACC OS X Build 012 — AI Command Engine

## Functional commands
- NEXT / N / LANJUT / L
- KONTEN / CONTENT
- POSTER
- CAPTION
- QC
- PUBLISH
- PSL / PAPA SAUCE LAB
- Known channel names
- Any other instruction becomes a new Mission

## Engine behavior
Commands can:
- Create Mission records
- Update Mission status
- Add Production Queue records
- Switch active Channel
- Open the appropriate ACC OS X module
- Write Command History
- Write Enterprise Database activity events
- Persist after refresh

This build uses local deterministic intent routing.
